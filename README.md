# Terran RTS

Играбельный клон классической RTS в духе StarCraft (Blizzard, 1998) для GitHub Pages.
Один расе — терраны — против ИИ. Полностью статический сайт: без бэкенда, без сборки,
без внешних библиотек. Вся графика рисуется кодом на Canvas, звук синтезируется
через Web Audio API.

## Как играть

Вы управляете синей стороной (внизу слева). Цель — уничтожить все постройки красных.
Поражение — если красные снесли все ваши.

1. Выделите рабочих и отправьте их на кристаллы минералов (ПКМ по кристаллу).
2. Постройте **Дом** (население) и **Казарму** (производство бойцов).
3. Соберите отряд морпехов и уничтожьте базу врага. Волны атаки ИИ будут расти.

### Управление

| Действие | Управление |
|---|---|
| Выделить юнита / здание | ЛКМ |
| Рамка выделения | ЛКМ + протянуть |
| Добавить к выделению | Shift + ЛКМ |
| Приказ: идти / добывать / атаковать | ПКМ (по земле / кристаллу / врагу) |
| Точка сбора для здания | ПКМ по земле при выделенном здании |
| Назначить группу 1…9 | Ctrl + цифра (или Shift + цифра) |
| Выбрать группу | 1…9 |
| Строить (рабочим) | B, затем Q/W/E — ЦК/Дом/Казарма |
| Производство (в здании) | Q |
| Отменить заказ в очереди | Клик по значку в очереди (минералы вернутся) |
| Стоп | S |
| Пауза | P или кнопка |
| Отмена / снять выделение | ESC |
| Камера | Стрелки или мышь у края экрана |
| Камера через миникарту | ЛКМ по миникарте (ПКМ — приказ туда) |

Здание можно ставить только на разведанной территории (снимите туман войны разведчиком).
Рабочие автоматически носят минералы в ближайший командный центр; новые рабочие
сразу идут добывать сами.

## Структура проекта

```
index.html        — точка входа
style.css         — стили интерфейса
.nojekyll         — отключает Jekyll на GitHub Pages
js/
  config.js       — ВСЕ числовые параметры (баланс в одном месте)
  map.js          — карта 64×64, генерация рельефа, кэш отрисовки
  pathfinding.js  — A* по тайловой сетке + сглаживание пути
  units.js        — юниты: движение, добыча, бой, эффекты
  buildings.js    — здания, стройка, очереди производства
  fog.js          — туман войны (3 состояния клетки)
  ai.js           — ИИ противника (экономика + растущие волны)
  ui.js           — панель команд, миникарта, тосты, экраны
  input.js        — мышь, клавиатура, камера
  audio.js        — синтез звука (Web Audio API, без файлов)
  game.js         — игровой цикл, команды игрока, победа/поражение
```

## Технические детали

- **Игровой цикл**: фиксированный шаг логики 1/30 с, отрисовка через
  `requestAnimationFrame` с интерполяцией позиций; пауза при неактивной вкладке.
- **Поиск пути**: A* на 8 направлений без среза углов, частичный путь при
  недостижимости, сглаживание по линии видимости; юниты расталкиваются
  (пространственный хэш), поэтому не слипаются в одну точку.
- **Производительность**: рельеф кэшируется на offscreen canvas 2048×2048 (в кадре —
  один `drawImage` видимого куска), туман — ImageData 64×64, растянутая на экран;
  отрисовываются только юниты/тайлы в вьюпорте. Цель — 60 FPS при ~200 юнитах.
- **Звук**: включается только после первого клика (политика автовоспроизведения);
  кнопка «Звук» в верхней панели, состояние — в localStorage (в try/catch).
- **Совместимость**: современные десктопные Chrome / Firefox / Edge / Safari,
  управление мышью и клавиатурой. Сеть не используется — после загрузки страница
  работает офлайн.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub (например, `terran-rts`), без авто-инициализации.
2. В папке проекта:

   ```bash
   git init -b main
   git add -A
   git commit -m "Terran RTS"
   git remote add origin https://github.com/<username>/<repo>.git
   git push -u origin main
   ```

3. Откройте **Settings → Pages** → Source: *Deploy from a branch* →
   Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минут игра будет доступна по адресу
   `https://<username>.github.io/<repo>/`.

Файл `.nojekyll` уже в репозитории — он нужен, чтобы GitHub Pages отдавал
папку `js/` с ES-модулями как есть, без обработки Jekyll. Обновления
подхватываются обычным `git push` в `main`, шаг сборки не требуется.
